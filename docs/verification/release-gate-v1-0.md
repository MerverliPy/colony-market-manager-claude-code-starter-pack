# release-gate-v1-0.md

## Release Gate
The 1.0 release is ready only if all are true:

- full migration chain is verified
- no known deadlock class is unresolved at ship severity
- industrial, valuables, prestige, and regional trade strategies are all viable
- onboarding exists for first-time players
- readability and accessibility pass is complete
- deferred items are documented and non-fatal

## Evidence to Gather
- migration test results
- balance simulation summaries
- route validation output
- deadlock regression checks
- tutorial/advisor walkthrough notes
- final known-issues review
