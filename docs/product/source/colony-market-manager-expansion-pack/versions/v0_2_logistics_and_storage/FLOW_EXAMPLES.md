# Flow Examples — v0.2 Logistics & Storage

## Example A: Food chain
Farm -> Storage Shed -> Granary -> Market Stall

### Failure case
Farm output overfills shed, grain sits in open yard, freshness drops, sale value declines.

### Improved case
Granary reserves food slots, carriers prioritize perishables, preserved food buffers demand swings.

## Example B: Tool production
Ore -> Warehouse -> Workshop -> Tool Depot -> Caravan staging

### Failure case
Ore and tools compete for the same storage, workshop starves while finished goods clog routes.

### Improved case
Tool Depot reserves finished goods slots and frees warehouse space for industrial inputs.
