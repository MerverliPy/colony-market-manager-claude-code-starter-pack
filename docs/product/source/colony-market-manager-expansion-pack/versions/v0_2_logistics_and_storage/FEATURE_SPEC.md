# Feature Spec — v0.2 Logistics & Storage

## Release intent
Turn internal colony flow into a meaningful optimization problem.

## Player-facing goals
The player should be able to:
1. reserve storage by category
2. detect hauling bottlenecks
3. choose between cheap storage and specialized storage
4. reduce spoilage and overflow loss
5. optimize layout for throughput

## Included
- storage priority rules
- spoilage and decay
- cold storage and granary
- overflow handling
- hauling queue visualization
- route congestion effects

## Excluded
- external regional routes
- specialist worker XP
- district zoning

## Success conditions
- bad layouts produce visible losses
- better storage choices produce measurable margin gains
- storage decisions are understandable from the UI
